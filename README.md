# BScThesis_Mathematics
Data and code for the stochastic modelling and analysis of Energy Hubs

## Repository overview
The project follows a modular workflow in which data are collected, preprocessed, transformed into stochastic scenarios, used to solve the optimization models, and finally analysed through performance metrics and graphical visualizations.

## Repository documentation

Each main directory contains its own README.md file describing the purpose of its scripts and how they should be used.

For every Python script, the documentation includes:

Purpose – What the script does.
Inputs – Required input files and data.
User-configurable parameters – Variables that can be modified safely.
Outputs – Files and results generated by the script.
Dependencies – Other scripts or data required for execution.
Execution order – When the script should be executed within the computational workflow.

This documentation is intended to facilitate the reproduction of the results presented in the thesis and the reuse of the code in future research.
