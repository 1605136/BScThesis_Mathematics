# Data (`data`)

## Purpose

This directory contains the scripts used to download, preprocess and generate the datasets required by the Energy Hub optimization models.

The generated datasets are subsequently loaded by the modules in `src/` to formulate and solve the optimization models.

## Directory contents

| File | Description |
|------|-------------|
| `download_omie.py` | Downloads electricity market data from OMIE for the selected year. |
| `generator_el_prices.py` | Processes electricity market price data. |
| `generator_gas_prices.py` | Processes natural gas price data. |
| `generator_wind_production.py` | Processes wind power generation data. |
| `generator_demand.py` | Processes electricity, heating and cooling demand data. |
| `generator_historical_data.py` | Combines all processed datasets into a single historical dataset (`historical_data.csv`). |
| `generator_scenarios.py` | Generates representative stochastic scenarios from `historical_data.csv` using time-series aggregation based on the **k-medoids** clustering algorithm implemented in **TSAM (Time Series Aggregation Module)**. |

## Directory structure

| Directory | Description |
|-----------|-------------|
| `raw/` | Original datasets collected from external sources. |
| `processed/` | Processed datasets and generated files used as inputs for the optimization models. |

## User-configurable parameters

The only parameter that needs to be modified is the number of representative scenarios:

```python
N_SCENARIOS = 10
```

This parameter specifies the number of representative days (clusters) generated by `generator_scenarios.py`.

## Outputs

The scripts in this directory generate the datasets required by the optimization models.

| File | Description |
|------|-------------|
| `historical_data.csv` | Consolidated historical dataset generated from the processed input datasets. |
| `scenarios_{N_SCENARIOS}.csv` | Representative days obtained through k-medoids clustering, together with their associated occurrence probabilities. |

The generated files are stored in the `processed/` directory.

### `historical_data.csv` format

The historical dataset contains one row per hour and follows the general structure:

```text
date, hour, parameter_1, parameter_2, ..., parameter_n
```

where:

- `date` identifies the day.
- `hour` identifies the hourly time period.
- `parameter_i` denotes one of the variables required by the optimization models.

## Notes

The processed datasets are already included in the repository. Therefore, the optimization models can be reproduced without executing the scripts in this directory.

The data-generation scripts are only required if the user wishes to regenerate the historical dataset or generate a different number of representative stochastic scenarios.
