# Performance metrics (`metrics`)

## Purpose

This directory contains the scripts used to evaluate the performance of the optimization models.

The metrics are computed from the optimization results generated by the execution scripts in `run/` and are used to compare deterministic and stochastic formulations.

## Directory contents

| File | Description |
|------|-------------|
| `metrics_EH1_run.py` | Computes the performance metrics for the EH1 model. |
| `metrics_EH2_run.py` | Computes the performance metrics for the EH2 model. |
| `metrics_EH3_run.py` | Computes the performance metrics for the EH3 model. |

## Inputs

The scripts require the optimization results stored in the `outputs/` directory, including:

| Input | Description |
|-------|-------------|
| `params.xlsx` | Technical, economic and operational parameters of the Energy Hub models. |
| `historical_data.csv` | Historical dataset used to reconstruct the optimization instances. |
| `scenarios_*.csv` | Representative stochastic scenarios and their associated probabilities. |

## User-configurable parameters

Before executing a script, the user may modify:

```python
study_day = "2026-05-20"
```

The required date format is:

```text
YYYY-MM-DD
```

## Outputs

Each script computes the performance metrics associated with the corresponding Energy Hub model and displays the results in the console.

## Notes

These scripts should be executed only after the corresponding optimization results have been generated using the scripts in the `run/` directory.
